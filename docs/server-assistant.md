# 服务器助手配置

## 基础配置

生产环境需要 PostgreSQL 和两个服务器助手密钥：

```text
DB_URL=jdbc:postgresql://数据库地址:5432/ai_platform
DB_USERNAME=数据库用户
DB_PASSWORD=数据库密码
SERVER_ASSISTANT_ACCESS_TOKEN=页面访问口令
SERVER_CREDENTIAL_MASTER_KEY=32字节Base64主密钥
```

主密钥可使用 `openssl rand -base64 32` 生成。它不会写入数据库；丢失或更换后，已经保存的密码和
私钥无法解密，需要在页面逐台重新录入。

## 添加服务器

进入 `/server/assistant/`，打开“服务器配置”，填写：

1. 名称、地址、SSH 端口和用户名。
2. 用户名加密码，或用户名加私钥。凭据提交后会加密，重新编辑时留空表示不修改。
3. `ssh-keyscan` 输出的完整主机公钥记录。非 22 端口的主机格式通常为 `[host]:port`。
4. 保存后使用“测试连接”单独验证认证与主机密钥，不会执行远端命令。

`ssh-keyscan` 的结果必须通过云厂商控制台或服务器控制台核对指纹，不能把网络扫描结果直接当作可信身份。

## 配置命令

新服务器保存成功后会自动添加“系统概览、CPU 与内存、磁盘使用、高资源进程、最近系统告警、Docker
容器状态”六个常用只读命令，不需要逐条录入。已有服务器可以在命令区点击“补充常用命令”；该操作
只补充缺少的同名命令，不会覆盖已经修改过的配置，也不会重复创建。

每条命令都属于一台服务器，并包含名称、用途、命令模板、参数定义和风险等级：

- 普通：模型按需直接执行，适合 `uptime`、`free -m`、状态和只读日志查询。
- 危险：只生成确认选项，适合重启、部署、修改配置或其他会改变状态的命令。

当用户提出的任务没有对应命令时，助手会生成名称、用途和命令模板，并在回复下方显示“添加命令”
选项。服务端会按只读命令白名单自动判定风险；含 Shell 控制符、修改类子命令或其他无法证明只读的内容
一律判为危险。用户确认前不会写入数据库，确认后也只添加到当前对话选择的服务器，不会同步到其他服务器。

确认添加普通命令后，页面会使用服务端签发的一次性续跑凭证恢复同一对话，助手会重新读取命令清单并继续
原任务，不需要用户再发一条“继续”。添加危险命令只代表允许助手选择它，续跑后实际执行时仍会出现第二个
“执行”确认选项；确认执行后，真实输出也会回到同一对话供助手继续分析。确认和取消既可点击按钮，也可
直接回复“执行”或“取消”，两种交互会消费同一个服务端一次性操作。取消添加或取消执行会追加明确的
结束消息，不再调用模型。手动新增、编辑和删除命令的入口继续保留，方便精确维护。已经保存的固定命令仍以配置的
SSH 用户身份运行；Linux 拒绝执行时，需要在服务器侧为这个账号授予对应权限。必须遵循最小权限原则，
例如只为确实需要的固定操作配置精确的免密 sudo 规则，不要授予不受限的 `sudo ALL`。

命令模板使用 `{{name}}` 表示可变参数，占位符必须独占一个 Shell 参数。参数定义是 JSON 数组，支持
`PATH`、`ENUM`、`INTEGER`、`TEXT`：路径必须声明 `allowedRoots`，枚举必须声明 `allowedValues`，整数可设置
上下限，文本可设置长度和正则。服务端校验后统一做 POSIX Shell 单引号转义，同时拒绝路径 `..` 越界、
换行和空字节。因此 `ls -la {{path}}` 可安全复用 `/var/log/nginx`、`/srv/apps/demo` 等不同路径，无需每个
路径新增一条命令。

## 自定义模型提供方

“服务器配置”顶部可新增 OpenAI 兼容提供方，填写基础地址、Chat Completions 路径、API 密钥和模型列表。
模型列表每行格式为“显示名称 | 模型编号 | 推理等级”，不支持推理等级的提供方留空即可。API 密钥使用与 SSH
凭据相同的 AES-256-GCM 主密钥加密，读取接口只返回“已配置”状态。保存后可以在对话页顶部切换模型，确认
命令后的自动续跑也会沿用该对话当前选中的模型。这里接入的是 OpenAI 兼容 API；某个 Coding 套餐是否能用，
仍取决于套餐是否允许 API 调用、提供的基础地址和模型编号是否正确。

## 对话与数据边界

新建对话时先选择服务器。同一对话固定绑定这一台服务器，切换选择会自动新建对话。聊天当前只保存
在浏览器本地；“近期对话”的管理模式支持全选或多选删除。删除时先由服务端同步清理该对话的模型记忆、
服务器绑定、待确认执行、待确认命令提议和未消费的续跑凭证，再删除浏览器记录；全部删除后会自动创建一个空白对话。数据库仅包含
`server_assistant_server`、`server_assistant_command`、`server_assistant_model_provider` 和
`server_assistant_model` 四类配置。
